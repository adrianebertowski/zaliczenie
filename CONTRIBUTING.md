# CONTRIBUTING

## Tworzenie branchy

Branch należy nazwać według schematu:

zwierze-imie

Przykład:

lemur-adrian

## Commity

Commity powinny jasno opisywać zmiany.

Przykłady:

- Dodano zdjecie lemura

- Dodano sekcje lemur

## Pull Request

Każda zmianę należy przesłać w osobnym Pull Requeście.

## Komunikacja

Wszelkie uwagi należy zgłaszać poprzez Pull Request lub Issues.
